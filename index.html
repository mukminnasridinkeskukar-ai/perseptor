Hubungkan ke Supabase

Frontend ini dihosting statis (GitHub Pages) dan membutuhkan backend Supabase untuk penyimpanan data permanen.

  1. Buat proyek di supabase.com (gratis).
  2. Buka SQL Editor → jalankan file schema.sql (disertakan dalam paket).
  3. Salin Project URL dan anon public key dari Settings → API.

Mode Demo hanya untuk pratinjau — data disimpan di browser ini saja, bukan database permanen.
